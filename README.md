## 给朋友的使用步骤

1. 下载上面的 ZIP 并解压，打开其中 `zhiju-rag-v5/README.md`，这是完整安装与排错说明。
2. 按其中 `docs/BACKEND_COMPATIBILITY.md` 准备匹配版本的 **RAGFlow + Elasticsearch**，应用随包附带的最小检索补丁；不能直接替换成任意 RAGFlow 版本。
3. 在自己的 RAGFlow 建立知识库，导入并完成解析；嵌入模型使用本地 Ollama `bge-m3`。完整回答需配置自己的 Kimi/Moonshot 账号和密钥。
4. 准备 Python 3.12，在解压目录执行：

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
ollama pull bge-m3
python -m tools.prepare_model --download
```

Qwen 重排模型约 1.2 GB，明确执行下载命令才下载，应用不会自动下载。

5. 编辑 `.env`，填写自己的 RAGFlow 容器名、知识库 ID、CHAT 模型记录 ID、Ollama 模型 digest。密钥仅配置在自己的 RAGFlow 中，不放入本仓库或 `.env`。
6. 检查并启动：

```bash
python -m tools.run check --cloud
python -m tools.run serve --cloud
```

7. 终端保持运行，打开 [本机助手](http://127.0.0.1:8772/)，页面显示就绪后提问。完整问答需阅读并勾选每题的云端许可；不勾选只做本地检索。按 `Ctrl-C` 停止，不会删除资料。

推荐 macOS / Linux；Apple Silicon 可用 `QWEN_DEVICE=mps`，其他机器默认 `cpu`（较慢）。原生 Windows/CUDA 未验收。没有准备后端和资料时，不能只运行网页就得到知识库答案。

## 怎么问

- 写明主体、年份、金额、含税与否等条件，再提出想确认的问题。
- 回答后展开原文与计算步骤；有引用不代表法律适用性绝对正确。
- 更正金额/期间时选择“继续追问最近完成的一题”，换话题选择“新问题”。
- 后端仅保留最近一题 15 分钟；页面历史最多 20 条，刷新即清空。多标签页共享任务，不是多用户隔离服务。

## 隐私与安全

默认只监听自己的回环地址。**不要公网穿透 8772，也不要把数据库或 Docker socket 暴露给朋友。**
云端许可后，提问与每次最多 20 条 / 12000 字符必要证据会发给 Moonshot/Kimi；敏感文档请先确认外发授权。不会把整库上传给模型，但选中片段仍可能含隐私。

私有仓库不会自动让朋友可见：所有者可在 GitHub 的 Settings → Collaborators 中邀请朋友，或者直接私下发送这个脱敏 ZIP。不要为了下载方便改成公开。
